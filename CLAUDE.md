# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Solvers is a marketplace of AI specialists ("solvers") that plug into Claude and ChatGPT through a single MCP connector (`https://solvers.wondervelop.com/mcp`). A solver is a data package (method steps with checklists, knowledge base, templates, evals), not code. Buying one mints a **license NFT (Metaplex Core)** into the user's Solana wallet; reviews, credits, guarantees (escrow), staking and license resale are on-chain (currently **devnet**, mainnet planned). Creators publish solvers and earn from sales; buyers can also pay by Pix (Mercado Pago) or SODAX. Docs are in Portuguese: `README.md` (overview + decisions), `INSTRUCTIONS.md` (full spec), `PACKAGE_SPEC.md` (solver package format), `docs/` (resale, devnet upgrade, mainnet runbook, CI notes, manual test scripts).

Also read `AGENTS.md` (Anchor program rules; skills in `.agents/skills/` are NOT auto-loaded, read the `SKILL.md` before touching that area) and `apps/web/AGENTS.md` (the installed Next.js and Turborepo differ from training data: check `node_modules/next/dist/docs/` and the turbo package docs first).

## Stack

- **Monorepo**: pnpm 10 + Turborepo, Node >= 22, TypeScript, `tsx`. Tests use `node:test`.
- **Program** (`programs/solvers`): Rust, Anchor 1.2, `anchor-spl`, `mpl-core`, tested with LiteSVM; built with `--arch v1`. Only buildable in WSL/Linux.
- **Chain client**: `@solana/kit` (not web3.js), `@solana-program/*`, client generated by Codama from the Anchor IDL. The platform is the fee payer for every transaction (users need no SOL). USDC is a self-minted test mint with an API faucet.
- **Server** (`apps/server`): Express, Drizzle ORM + Postgres 16 with pgvector, `@modelcontextprotocol/sdk`, `jose` (JWT), `tweetnacl` (SIWS), `zod`, `sharp`, local embeddings via `@huggingface/transformers` (multilingual-e5-small).
- **Web** (`apps/web`): Next.js App Router + React, Privy (email login/embedded wallet), `@solana/kit`.
- **External services**: Solana RPC + Helius webhook, Privy, Mercado Pago (Pix), SODAX, Cloudinary (images), Telegram (admin alerts), Docker (deliverable verifier sandbox).
- **Infra**: single VPS, PM2 + nginx, one domain (`/` web, `/api`, `/mcp`, `/oauth`, `/.well-known` server), Postgres on port 5433. See `infra/` and `VPS_GUIDE.md (guia privado)` before any infra/port/nginx/PM2 change.

## Commands

```bash
pnpm install
pnpm build | typecheck | test          # root, via turbo
pnpm --filter @solvers/shared --filter @solvers/client --filter @solvers/chain build   # needed before the server
pnpm --filter @solvers/server dev      # API/MCP, reads apps/server/.env
pnpm --filter @solvers/web dev         # web on :3000
pnpm --filter @solvers/server db:generate | db:migrate
pnpm --filter @solvers/client generate # regenerate client after the program/IDL changes
cd apps/server && node --env-file-if-exists=.env.test --import tsx --test test/trial.test.ts   # one server test
cd packages/shared && node --import tsx --test src/rules.test.ts                                # one package test
bash scripts/chain/build-program.sh | test-program.sh   # WSL only; BUILD=1 rebuilds the .so before testing
bash infra/deploy.sh                   # deploy current commit to the VPS
```

- `*.db.test.ts` only run with `TEST_DATABASE_URL` pointing to a **disposable** migrated Postgres. `127.0.0.1:5433` is the dev Postgres in WSL with real data: use a `pgvector/pgvector:pg16` container on another port for writes.
- Authenticated route tests need no Privy or chain: `createApp([])` + `signSession(wallet)` from `auth/jwt.ts`.
- E2E (server running): `cd scripts && npx tsx src/e2e-full.ts` (also `e2e-purchase`, `e2e-api`, `e2e-mcp`); solver evals: `cd scripts && npm run eval [slug]`.

## Rules that are not obvious from the code

- Program: no `unwrap`/`expect`/`panic`, `checked_*` arithmetic, validate token accounts by address and mint, no new `init_if_needed`, never change existing account layouts (devnet already has them). Review with the `solvers-program-review` skill.
- **Never `git push` (auto-deploys `master`) before the devnet program upgrade is done** (`docs/devnet-upgrade.md`): a new server against the old program creates unrecoverable escrows. `RESALE_ENABLED` stays off until that upgrade.
- Every purchase (license, credits, guarantee) must be >= `min_price` (5 USDC) to cover rent paid by the platform.
- License caps are enforced by the program, not the server: `purchase_license` requires the `supply_cap` PDA (derived from the agent) and fails with `SoldOut` when `Agent.total_sales >= max`; the cap can only be raised and resale/transfer never frees a slot. Never say "only N will exist" (the creator can raise it). Program changes need WSL (`scripts/chain/test-program.sh`).
- Outside mainnet, `PIX_SIMULATE` and `SODAX_SIMULATE` default to true; the mainnet env rejects simulation and admin shortcuts.
- Migrations share one DB with the release still running: keep them backward compatible.
- Keys and `.env*` live outside git (`~/solvers-keys` in WSL, `apps/server/.keys`).
